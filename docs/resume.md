# FasalBima Sathi

- **Objective:** Make crop insurance rules easier to understand through multilingual guidance, premium estimates and timely crop-loss reporting information.
- **Approach:** Built a FastAPI, LangGraph and Streamlit assistant using official PMFBY documents, cited retrieval, Groq inference and confirmed Python calculations; deployed with Docker and GitHub Actions.
- **Impact:** Reduced median repeat-answer latency by 78.46% (1.75 s to 0.38 s) across five local live-provider test pairs, with zero additional LLM calls on cache hits; verified reliability with 120 automated tests.

Measurements describe a small controlled benchmark, not farmer adoption or claim outcomes.
